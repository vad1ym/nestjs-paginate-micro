# Changelog

## v1.0.0

First public release.

### 🚀 Enhancements

- Filter-first pagination for MikroORM repositories and SQL query builders, with offset and cursor pages.
- Metadata-aware filters, search, sorting, relations, JSON paths, soft delete, and Swagger decorators.
- PostgreSQL, MariaDB/MySQL, and SQLite dialects; tested with MikroORM 6/7 and NestJS 11/12.
